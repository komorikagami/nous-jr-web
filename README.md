# ヌースジュニア プログラミングスクール サイト

## 概要

本リポジトリは「ヌースジュニアプログラミングスクール」の公式Webサイトです。
東海市で開催する子ども向けIT・プログラミング教育サービスの紹介ページとして設計されています。

シンプルな静的HTML構成で、スマホ・PC両対応のレスポンシブデザインを採用しています。

---

## コンセプト

* 考える力を育てるプログラミング教育
* 少人数制（2〜5名）による丁寧な指導
* Scratch / Web制作 / Pythonの3コース構成
* 実践を通じた学習（作品制作重視）

---

## 技術構成

* HTML5
* CSS3（変数・Grid・レスポンシブ対応）
* 静的サイト構成（JavaScriptなし）
