# ヌースジュニア プログラミングスクール サイト

## 概要

「ヌースジュニアプログラミングスクール」の公式Webサイトです。  
東海市で開催する小学生〜中学生向けプログラミング教室の情報提供・体験申込導線を目的としています。

現在は静的サイト（HTML/CSS）として構成されていますが、将来的には管理システムを含むWebアプリケーションへの拡張を前提とした設計方針を持っています。

---

## サイトの目的

- スクールの情報提供（コース・料金・特徴）
- 体験申込の導線設計
- 保護者向けの安心材料の提示（規約・プライバシー）

---

## コンセプト

- 考える力を育てるプログラミング教育
- 少人数制（2〜5名）による丁寧な指導
- Scratch / Web制作 / Python の3コース構成
- 作品制作を通じた実践型学習

## 対象ユーザー

- 小学生〜中学生の保護者
- プログラミング教育に興味のある家庭
- 東海市周辺エリアの利用者

---

## 技術構成

- HTML5（セマンティック構造）
- CSS3（変数・Grid・レスポンシブ対応）
- 静的サイト構成（JavaScriptなし）
- レスポンシブ対応

## 設計方針

- セマンティックHTML重視
- 情報の階層設計（h1〜h3）
- BEMライクなCSS設計
- モバイルファースト
- ユーザー不安の軽減（規約・体験説明）

---

## 開発方針

- セマンティックHTMLを重視（構造優先）
- classベースのCSS設計（BEMライク）
- 情報階層の明確化（h1 → h2 → h3）
- モバイルファースト設計
- JavaScript依存を極力排除した軽量構成

本システムは将来的に以下を含む**Webアプリケーション化**を想定しています。

### 1. 管理システム（Admin）

- 生徒・保護者管理
- 受講状況管理

### 2. スケジュール管理
- 開講日程の管理

- 日程確定フローの自動化

### 3. 受講管理
- コース・回数管理
- 出欠管理
- 振替管理

### 4. 申込システム
- 体験申込フォームの統合管理
- 入会申込フロー

### 5. 決済機能
- 月謝・スポット料金の管理
- オンライン決済対応（将来）

## 設計思想（将来拡張を見据えて）

- 静的サイト → Webアプリへの段階的移行を想定

- 画面設計は最初から情報単位で分割
